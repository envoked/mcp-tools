# Whoop
An [MCP](https://modelcontextprotocol.io/introduction) Server for pulling data from a [Whoop device](https://www.whoop.com/us/en/).

![Screencast](http://share.yoadrian.co/Screen-Capture-2025-07-23-19-03-01/Screen-Capture-2025-07-23-19-03-01.gif)

To install dependencies:

```bash
bun install
```

## Configuration:
This relies on a `WHOOP_TOKEN` environment variable being set.
